# 藥劑科報廢流程表製作（專案藍圖）

> 本檔為跨 Agent 通用的專案藍圖（AGENTS.md 開放標準）。任何 Agent 的每個 session 都應先讀本檔＋`handoff.md`。
> 本專案為獨立專案，聚焦於「藥劑科報廢流程表」之獨立表單製作、Code-First 打包與發布全流程。

## 專案簡介
佳里奇美醫院藥劑科報廢流程表單獨立製作專案。採用 Code-First 技術將高傳真 HTML 版面與全院 3,427 筆藥品即時連動邏輯，100% 原生轉譯打包為 Power Apps Canvas 應用程式，並提供醫院端無障礙發布與 Studio 手工建置 SOP 指南。

## 關鍵時程
- 2026-09-14：專案獨立初始化完成（L1 本地藍圖＋L3 Obsidian 第二大腦同步）。
- 2026-09-14：完成 HTML 1:1 數位孿生轉譯，產出實體應用程式（`佳里奇美_藥劑科報廢表單_原生正式版.msapp`）與全套操作 SOP。
- 2026-09-14：完成線上 Power Apps 互動除錯：鎖定報廢日期、流水號單號自動編碼、全表單一鍵深度淨空、報廢原因選項調整、送出寫入歷史清單（降冪排序、三層資訊），以及歷史紀錄 100% 完整原封還原點閱。
- 2026-09-17：完成 UI 緊湊化排版（全畫面文字元件零越界，底部安全餘裕擴至 86px），重構微軟原生表單 `Form_Attachment` 徹底打通 SharePoint 附件上傳通道並排除按鈕編譯錯誤。確立下次開工第一優先：SharePoint 申請人/複核人/藥庫複核人員三欄位重建為單行文字並補齊連動寫入。
